# Plan 01-01: 项目骨架 + PETALface 模型集成 + Embedding API

## Objective

搭建 `facerecserver` 包结构，集成 PETALface 模型和 MTCNN 人脸检测，实现人脸特征向量提取 API。

## Files to Modify

- `pyproject.toml` — 添加依赖
- `.gitignore` — 添加忽略规则
- `facerecserver/__init__.py` — 包初始化
- `facerecserver/__main__.py` — CLI 入口
- `facerecserver/app.py` — FastAPI 应用工厂
- `facerecserver/config.py` — YAML 配置加载
- `facerecserver/config.yaml` — 默认配置文件
- `facerecserver/face_detection/__init__.py`
- `facerecserver/face_detection/detector.py` — MTCNN 检测封装
- `facerecserver/face_detection/aligner.py` — 人脸对齐
- `facerecserver/face_recognition/__init__.py`
- `facerecserver/face_recognition/model.py` — PETALface 模型加载
- `facerecserver/face_recognition/embedding.py` — 特征提取
- `facerecserver/face_recognition/utils.py` — 图像预处理
- `facerecserver/api/__init__.py`
- `facerecserver/api/routes.py` — API 路由
- `facerecserver/api/schemas.py` — Pydantic 模型
- `scripts/download_model.py` — 模型下载脚本

### Task 4: PETALface 模型加载与特征提取

<read_first>
- `https://github.com/Kartik-3004/PETALface` — 模型源码和架构
- `https://huggingface.co/kartiknarayan/PETALface` — 权重定义
- `facerecserver/config.py` — 读取模型配置
</read_first>

<action>
1. 创建 `facerecserver/face_recognition/model.py`:
   - 研究 PETALface GitHub 源码，提取模型定义（Swin Transformer backbone + LoRA）
   - 实现 `PETALFaceModel` 类:
     - `__init__(model_path, device)` — 加载 PyTorch 权重
     - `forward(x) -> torch.Tensor` — 前向推理，返回 embedding
     - 设置 `model.eval()` 和 `torch.no_grad()`
   - 如果 PETALface 有自定义模型结构，需在本地重现模型定义
   - 加载权重时使用 `map_location` 支持 CPU
2. 创建 `facerecserver/face_recognition/embedding.py`:
   - `FaceEmbeddingExtractor` 类:
     - 组合 `FaceDetector` + `align_face` + `PETALFaceModel`
     - `extract(image) -> np.ndarray` — 完整流水线
     - `extract_from_file(path) -> np.ndarray` — 从文件读取
     - `extract_from_base64(base64_str) -> np.ndarray` — 从 Base64
   - 简单质量检查: 亮度均值、拉普拉斯方差（模糊检测）
3. 创建 `facerecserver/face_recognition/utils.py`:
   - `preprocess_image(image, target_size)` — 图像归一化
   - `load_image(path)` — 支持中文路径的图片加载
   - `base64_to_image(base64_str)` — Base64 解码
   - `check_image_quality(image)` — 简单质量检查
4. 创建 `facerecserver/face_recognition/__init__.py`
</action>

<acceptance_criteria>
- `PETALFaceModel` 成功加载预训练权重，无错误
- `forward()` 返回 512-d 向量
- `extract()` 完整流水线: 检测→对齐→归一化→推理
- 同一人两张照片 embedding 余弦相似度 > 0.5
- 不同人两张照片 embedding 余弦相似度 < 0.3
- 中文路径图片正常加载
- 模糊/过暗图片被拒绝并返回错误
</acceptance_criteria>

### Task 5: Embedding API

<read_first>
- `facerecserver/face_recognition/embedding.py` — 特征提取流水线
- `facerecserver/config.py` — 服务器配置
</read_first>

<action>
1. 创建 `facerecserver/api/schemas.py`:
   - `EmbeddingRequest` — 包含 `image` (base64), `image_url` (URL), `threshold` (质量阈值)
   - `EmbeddingResponse` — `{"code": 0, "message": "success", "data": {"embedding": [...], "dimension": 512}}`
   - `ErrorResponse` — `{"code": -1, "message": "error description", "data": null}`
2. 创建 `facerecserver/api/__init__.py`
3. 实现 `POST /api/v1/embedding`:
   - 支持 File 上传、Base64、URL 三种输入
   - 调用 `FaceEmbeddingExtractor.extract()`
   - 返回统一格式
   - 异常处理: 无人脸、质量不合格、模型未加载等
4. 创建 `facerecserver/app.py`:
   - `create_app()` 工厂函数
   - 注册路由
   - 在应用启动时预加载模型 (`lifespan` 事件)
   - CORS 支持 (供后续 Vue 前端调用)
5. 更新 `facerecserver/__main__.py` 使用 `uvicorn.run(app)`
6. 验证: 启动服务后访问 `/docs` 显示 Swagger 文档
</action>

<acceptance_criteria>
- `POST /api/v1/embedding` 返回 `{"code": 0, "message": "success", "data": {"embedding": [...]}}`
- 支持 File 上传、Base64、URL 三种输入
- 无人脸时返回 `{"code": 1001, "message": "未检测到人脸"}`
- 图片质量不合格时返回 `{"code": 1002, "message": "图片质量不合格"}`
- 模型未加载时返回 `{"code": 5000, "message": "模型未加载"}`
- `/docs` 可访问，显示 Swagger 文档
- CORS 已启用
- `python -m facerecserver` 可启动服务
</acceptance_criteria>

## Risks

| 风险 | 影响 | 缓解 |
|------|------|------|
| PETALface 模型结构复杂，需研究源码 | 高 | 提前研究 GitHub 仓库，必要时简化 |
| CPU 推理速度较慢 (Swin Transformer) | 中 | 考虑模型量化，或后续加 ONNX |
| mtcnn 包在 CPU 上检测速度 | 低 | MTCNN 足够快，可接受 |
| OpenCV 不支持中文路径 | 低 | 使用 PIL 代替 OpenCV 读取 |
